## 原版内部读取机制对应

| 原机制 | 新版路径和差异 |
|---|---|
| csHook 密码文本提取 | 不提供；控件密码属性/未知保护状态导致拒绝读取 |
| rsHook WH_CALLWNDPROC + EM_STREAMOUT | 独立重写x86/x64固定DLL；采用文档化SF_RTF，保留原始字节。原版0x12组合没有照抄 |
| msHook 桌面WH_CALLWNDPROC菜单捕获 | 选定目标线程模式；桌面模式须另确认且限时、一次、明确架构，始终显示捕获指示 |
| ListView跨进程数据缓冲区 | 不提供通用内存接口；固定目标控件内LVM_GETCOLUMNW/LVM_GETITEMW读取，返回有界结构化数据 |
| TreeView跨进程数据缓冲区 | 固定目标控件内TVM_GETITEMW/TVM_GETNEXTITEM遍历，返回有界层级 |
| 原共享名CoralSpy | 每请求随机私有IPC，确认PID/TID/HWND、同用户/同完整性级别、架构和长度 |

## 明确差异和未能验证的部分

- 密码、受保护进程、跨用户/不同完整性级别不读取，不提权。
- 全局菜单只在明确选择的x86或x64范围一次捕获，最长10秒，不持续监听。菜单快照在初始化处理前取得，动态项目可能未更新。
- 固定上限：512行×32列、1,024树/菜单记录、32层、每段2,048个UTF-16单元、结果1MiB。导出“全部”是全部已捕获，非无限量。
- Owner-data ListView不支持Hook；UIA未公开或虚拟化条目不能假装已读取。
- UIA导出RTF仅保留文本；Hook导出保持目标返回的完整SF_RTF字节，不保证任意嵌入对象/目标私有格式可重现。
- IE/Flash依赖现存可访问MSHTML宿主；不安装淘汰引擎，现代浏览器不能当作此DOM桥接接口。
- Hook在目标线程执行。取消阻止后续读取并移除注册，不能强行中断目标已阻塞的窗口过程；卸载和临时文件清理可能延迟。
- 原版资源不能证明所有隐藏行为，布局采用对应顺序和紧凑比例，未声称逐像素保真。
- Windows 11运行、混合DPI、原生交互、Hook加载/卸载、真实控件与MSHTML行为尚未实测。不可把跨编译和单元测试称作完美验收。
