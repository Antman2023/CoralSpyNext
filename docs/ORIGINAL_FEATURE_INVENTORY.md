# CoralSpy 1.0 功能逐项清单

来源：用户提供的原版包内中英文 Delphi 窗体资源，标识 `CoralSpy v1.0`、`2004-07-31`。只做静态资源解析，没有执行旧程序。此清单枚举可恢复的界面入口；仅由控件名推断但不能证明的内部行为会单独注明。它不是“所有功能已验收”的声明。

## 取色（原客户区 476 × 46）

C01 拖动准星；C02 色块预览；C03 十进制 Windows COLORREF；C04 十六进制；C05 HTML 色值；C06 R/G/B 分量；C07 点击色块选择颜色；C08 数值可选择和复制。

## 选项（原客户区 305 × 230）

O01 显示主窗口热键；O02 显示取色器热键；O03 准星热键（原提示“按两次”）；O04 注册；O05 取消注册；O06 English/Chinese；O07 IE 高亮文字色；O08 IE 高亮背景色；O09 粗体；O10 实时预览；O11 确定保存；O12 取消不应用。

## 托盘菜单

T01 显示主窗口；T02 颜色拾取器；T03 选项；T04 关于；T05 退出；T06 图标恢复交互。Explorer 重启后的图标恢复是新版附加可靠性措施。

## 不应伪称能完全保真的部分

- 原版密码明文、注入式控件抓取不能作为绕过保护的理由。
- Windows 11 已不再提供传统 IE/Flash 的完整受支持运行形态。可检查现存 MSHTML 宿主，不安装旧引擎；现代浏览器页面内容须通过其公开 UIA 能力，不能冒充 DOM 源码接口。
- UIA provider 不提供的虚拟化条目不会凭空出现；Hook不支持owner-data ListView。RichEdit原始流只在受支持目标返回完整结果时保存，不保证任意嵌入对象完整可用。显示实际数量、截断/不可用原因。
- 内部事件处理代码未被静态资源证明的行为（例如“更多”的具体原动画）不能仅凭名字宣称逐像素/逐行为完全一致。
- 原版和新版都需要实际 Windows 桌面验收。交叉编译/静态资源比对不能代替实机测试。
